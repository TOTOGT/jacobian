What this repository is

This is a collection of mathematical statements about matrices and polynomials, each written in Lean 4 using the Mathlib library. Lean is a proof checker: if a file builds, every step of every proof in it was verified by Lean's kernel. There is no sorry (Lean's "proof omitted" marker) anywhere in the repository.

The project began as a check of the Jacobian-conjecture setting and moved to a set of self-contained results around it. It does not prove or disprove the Jacobian, Dixmier or Poisson conjectures. Those are famous open problems, and here they appear only as precise statements.

What it proves

ModuleResultStatus
SpectralDiagonalBound For a Hermitian complex matrix A, every diagonal entry satisfies |Aii| ≤ max |λ|, the largest absolute eigenvalue. proved
Poisson The standard symplectic Poisson bracket on ℚ[x₁…xₘ, y₁…yₘ] is skew-symmetric, obeys the Leibniz rule and satisfies the Jacobi identity. proved
Dixmier The Weyl-algebra commutation relation ∂ᵢ(xⱼp) − xⱼ∂ᵢp = δᵢⱼ·p. proved
PoissonJacobian A Poisson endomorphism of ℚ[x,y] has Jacobian determinant ±1. A standard reduction toward the Jacobian conjecture, not a proof of the Poisson conjecture. proved
DualDerivations Dual derivations built from the inverse Jacobian, in the special case where the determinant equals the constant −2 (three variables). This is one case, not the general conjecture. proved
StandardConjectures Finite-dimensional linear algebra steps (perfect pairings, injective ⇔ surjective) used in arguments about the standard conjectures. proved
Dixmier, Poisson The Dixmier conjecture and the Poisson conjecture, written as Lean statements. open, statement only

"Compiles" is not the same as "proves what its name says". Each row above describes what the theorem actually states. The two conjectures are definitions of a proposition, not theorems.

Check it yourself

You need elan (the Lean version manager). Mathlib and the Lean version are pinned by the committed lake-manifest.json and lean-toolchain, so the build is reproducible.

git clone https://github.com/TOTOGT/jacobian
cd jacobian
lake build

A successful build prints Build completed successfully. The first build downloads Mathlib's compiled cache and can take a while. A GitHub Actions workflow in .github/workflows/verify.yml runs the same build on every push.

Layout

Jacobian.lean is the umbrella module that imports everything. The other files are the modules in the table. README.md holds the theorem registry with proof notes.
